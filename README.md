# Google Homepage Clone

A front-end practice project inspired by Google's homepage, built using HTML and CSS.

**Live Demo:** [View the Website](https://riteshdev66.github.io/google-homepage-clone/)

## About the Project

This project recreates the visual layout of Google's homepage to practise front-end web development. It helped me apply HTML structure, CSS styling, layout techniques, and basic UI design.

This is an educational project and is not affiliated with Google.

## Features

- Google-inspired homepage layout
- Search bar UI
- Navigation links and action buttons
- Apps icon created using CSS
- Custom styling with CSS

## Technologies Used

- **HTML5** — to structure the webpage
- **CSS3** — to style the page and arrange its elements

## Getting Started

You can view the live website using the link above, or run the project locally.

1. Clone this repository:

   ```bash
   git clone https://github.com/riteshdev66/google-homepage-clone.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

- Using CSS Flexbox and Grid for layout

- Working with images and local asset paths
